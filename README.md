# RWB Science Crossword v2.7 Mobile

Mobile-friendly science crossword game built with Python and Tkinter for Android using Pydroid 3.

Created by Robert William Blennerhed in collaboration with ChatGPT as part of RWB Tech Lab.

---

## Features

- Smart crossword engine
- Mobile-friendly interface
- Autosave and autoload system
- Crossword statistics and progress tracking
- Intelligent answer checking
- Correct letter system
- 1000+ science and technology questions
- Touch-friendly Android design
- Built with pure Python and Tkinter
